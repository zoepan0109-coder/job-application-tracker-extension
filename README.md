# 秋招投递助手

适用于 Chrome 和 Microsoft Edge 的本地浏览器扩展。支持：

- Boss直聘、猎聘、LinkedIn 的岗位信息提取
- 公司招聘官网的通用提取
- 点击扩展按钮或页面右键菜单后提取当前岗位
- 仅在用户主动操作时显示确认表单，不自动弹窗
- 本地管理流程、下一步安排和跟进日期
- 导出与“2026 秋招投递进度计划表”字段一致的 CSV

当前版本：`0.4.1`

## 支持的网站

- Boss直聘
- 猎聘
- LinkedIn Jobs
- 使用标准 `JobPosting` 结构化数据的公司招聘官网
- 其他公司官网（使用标题、页面区块和关键词进行通用识别）

不同招聘网站可能随时调整页面结构。扩展采用“手动触发提取 + 保存前确认”的方式，
不会在浏览网页时自动弹窗，也不会静默写入记录。

## 下载与安装

本项目暂不通过 Chrome 商店分发，需要从 GitHub 下载 ZIP 后手动安装。整个过程不需要运行安装程序。

### 第一步：从 GitHub 下载

1. 打开本项目首页：
   [job-application-tracker-extension](https://github.com/zoepan0109-coder/job-application-tracker-extension)。
2. 点击文件列表右上方的绿色 `Code` 按钮。
3. 在弹出的菜单中点击 `Download ZIP`。
4. 浏览器通常会把文件保存到系统的“下载”文件夹：
   - macOS：Finder → 下载
   - Windows：文件资源管理器 → 下载
5. 找到 `job-application-tracker-extension-main.zip`，双击完成解压。

### 第二步：把解压后的文件夹放到固定位置

不要长期把扩展文件夹留在“下载”目录，也不要在安装后移动或删除它，否则浏览器可能无法继续加载扩展。

推荐保存位置：

- macOS：`文稿/浏览器扩展/秋招投递助手`
- Windows：`文档/浏览器扩展/秋招投递助手`

可以先新建“浏览器扩展”文件夹，再把解压后的
`job-application-tracker-extension-main` 移进去，并改名为“秋招投递助手”。

### 第三步：安装到 Chrome

1. 打开 Google Chrome。
2. 在地址栏输入 `chrome://extensions/`，按回车。
3. 打开页面右上角的“开发者模式”开关。
4. 点击页面左上角的“加载已解压的扩展程序”。
5. 在文件选择窗口中找到前面保存的“秋招投递助手”文件夹。
6. 单击选中整个文件夹，不要进入文件夹后选择某个 `.js` 或
   `manifest.json` 文件。
7. 点击右下角“选择”。
8. 扩展页面出现“秋招投递助手”卡片，即表示安装成功。

### 第四步：安装到 Microsoft Edge

1. 打开 Microsoft Edge。
2. 在地址栏输入 `edge://extensions/`，按回车。
3. 打开左侧或页面下方的“开发人员模式”开关。
4. 点击“加载解压缩的扩展”。
5. 找到并选中保存好的“秋招投递助手”文件夹。
6. 点击“选择文件夹”。
7. 扩展页面出现“秋招投递助手”卡片，即表示安装成功。

### 第五步：固定到浏览器工具栏

Chrome：

1. 点击地址栏右侧的拼图形“扩展程序”按钮。
2. 在列表中找到“秋招投递助手”。
3. 点击名称右侧的图钉，使图标固定在工具栏。

Edge：

1. 点击地址栏右侧的拼图形“扩展”按钮。
2. 找到“秋招投递助手”。
3. 点击右侧的眼睛或“在工具栏中显示”按钮。

## 手动记录一次岗位投递

1. 打开 Boss直聘、猎聘、LinkedIn Jobs 或公司的招聘官网。
2. 进入具体岗位详情页面。
3. 正常完成岗位投递。
4. 投递完成后停留在岗位详情页面。
5. 主动点击浏览器工具栏上的“秋招投递助手”图标。
6. 扩展会在此时读取当前页面，并提取公司名称、岗位名称、地点、岗位方向、
   投递日期和职位描述。
7. 核对提取结果，信息有误时可以直接修改。
8. 点击“保存投递”。

也可以在岗位页面空白处点击鼠标右键，然后选择“记录到秋招投递助手”。

扩展不会根据“投递成功”等网页文字自动弹出。只有点击扩展图标或右键菜单时，
才会读取和显示当前岗位信息。

## 查看和更新投递记录

1. 点击浏览器工具栏上的“秋招投递助手”图标。
2. 点击弹窗底部的“管理记录”。
3. 新页面会显示：
   - 总投递数
   - 进行中岗位数
   - 面试阶段岗位数
   - Offer/录用数量
   - 逾期待办数量
4. 可以直接修改“当前流程”“下一步安排”和“跟进日期”。
5. 可以通过搜索框查找公司或岗位，也可以按招聘流程筛选。

### 自定义岗位方向

默认岗位方向包含海外 To B 销售、国际业务开发、产品经理、数据分析、运营、
市场营销、大宗商品业务等常用选项。每位用户都可以修改：

1. 打开“管理记录”页面。
2. 点击搜索栏右侧的“岗位方向设置”。
3. 在弹窗中每行填写一个方向，可以新增、删除或改名。
4. 点击“保存设置”。

记录岗位时，“岗位方向”不是强制下拉框，也可以直接输入任意内容。例如产品经理、
用户研究、算法工程师、品牌运营或供应链管理。自定义设置只保存在当前浏览器中。

所有记录默认保存在当前浏览器的本地扩展存储中。Chrome 与 Edge
之间不会自动同步，同一浏览器的不同用户配置文件之间也不会自动同步。

## 导出为 Excel 可打开的文件

1. 点击工具栏中的“秋招投递助手”。
2. 点击“管理记录”。
3. 在管理页面右上角点击“导出 CSV”。
4. 浏览器会弹出文件保存窗口。
5. 推荐保存到：
   - macOS：`文稿/求职/投递记录`
   - Windows：`文档/求职/投递记录`
6. 文件名默认为 `秋招投递记录_日期.csv`，例如
   `秋招投递记录_2026-07-26.csv`。
7. 点击“保存”。
8. 双击 CSV 文件即可使用 Microsoft Excel、WPS 表格或 Apple Numbers 打开。

导出的字段包括公司名称、岗位名称、岗位方向、工作地点、优先级、投递渠道、
投递日期、当前流程、下一步安排、下一步日期、提醒状态、等待天数、岗位链接和备注。

CSV 是独立备份文件，不会与浏览器中的记录自动双向同步。建议每周导出一次，
并在重要面试或 Offer 进展后额外备份。

## 更新扩展

1. 回到 GitHub 项目页面，再次点击 `Code` → `Download ZIP`。
2. 解压新版本。
3. 用新版本文件替换固定位置中的旧扩展文件。
4. 打开 `chrome://extensions/` 或 `edge://extensions/`。
5. 找到“秋招投递助手”。
6. 点击卡片上的圆形“重新加载”按钮。
7. 刷新已经打开的招聘网页。

覆盖文件前建议先从“管理记录”页面导出 CSV 备份。正常覆盖源代码不会清除浏览器本地记录，
但卸载扩展或清除扩展数据可能导致记录丢失。

## 常见问题

### 文件选择窗口里找不到扩展

不要在整个 Mac 或电脑中搜索长文件名。先把解压后的文件夹移动到“文稿/浏览器扩展”
或“文档/浏览器扩展”，再从文件选择窗口左侧进入对应目录。

### “选择”按钮是灰色的

需要选中整个扩展文件夹，不能选择 ZIP，也不能只选择 `manifest.json`。

### 点击扩展后没有识别岗位信息

确认当前停留在具体岗位详情页面，然后刷新页面并再次点击工具栏中的扩展图标。
公司官网结构差异较大，提取结果应在保存前核对。

### 在工具栏找不到扩展图标

点击地址栏右侧的拼图按钮，在扩展列表中找到“秋招投递助手”，然后点击图钉或
“在工具栏中显示”。

### 记录会上传到网络吗

不会。当前版本没有服务器和账号系统，数据只保存在用户自己的浏览器中。

## 隐私

记录保存在浏览器本地的扩展存储中，不会上传到服务器。清除浏览器扩展数据或卸载扩展前，请先导出备份。

扩展需要读取招聘页面内容以识别岗位信息，但不会收集密码、Cookie、浏览历史或简历文件。
