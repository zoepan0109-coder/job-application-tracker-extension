# 秋招投递助手

适用于 Chrome 和 Microsoft Edge 的本地浏览器扩展。支持：

- Boss直聘、猎聘、LinkedIn 的岗位信息提取
- 公司招聘官网的通用提取
- 检测“投递成功 / Application submitted”等提示后弹出确认
- 点击扩展按钮或页面右键菜单手动记录
- 本地管理流程、下一步安排和跟进日期
- 导出与“2026 秋招投递进度计划表”字段一致的 CSV

当前版本：`0.2.0`

## 支持的网站

- Boss直聘
- 猎聘
- LinkedIn Jobs
- 使用标准 `JobPosting` 结构化数据的公司招聘官网
- 其他公司官网（使用标题、页面区块和关键词进行通用识别）

不同招聘网站可能随时调整页面结构。扩展采用“自动提取 + 保存前确认”的方式，避免错误信息被静默写入。

## 安装

本项目不通过 Chrome 商店分发，采用下载源码 ZIP 后手动安装的方式：

1. 在 GitHub 项目页面点击 `Code` → `Download ZIP`。
2. 双击下载的 ZIP 文件完成解压。
3. 打开 Chrome 的 `chrome://extensions/`，或 Edge 的 `edge://extensions/`。
4. 开启右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择解压后的 `job-application-tracker-extension-main` 文件夹。
7. 建议将“秋招投递助手”固定在浏览器工具栏。

更新版本时，重新下载并解压最新版文件，替换旧文件夹后，在扩展管理页面点击该扩展的刷新按钮。

## 使用

投递成功后，扩展会尝试弹出确认框。核对公司与岗位后点击“保存投递”。

若未自动弹出，可点击工具栏扩展按钮，或在招聘页面右键选择“记录到秋招投递助手”。

点击“管理记录”可更新招聘流程并导出 CSV。CSV 可以用 Excel 直接打开，也可复制到已有秋招进度工作簿。

## 隐私

记录保存在浏览器本地的扩展存储中，不会上传到服务器。清除浏览器扩展数据或卸载扩展前，请先导出备份。

扩展需要读取招聘页面内容以识别岗位信息，但不会收集密码、Cookie、浏览历史或简历文件。

## 已知限制

- 浏览器安全机制不允许扩展直接修改任意本地 `.xlsx` 文件，因此当前通过 CSV 与 Excel 衔接。
- 对非标准公司官网的识别效果取决于页面结构；若字段缺失，可在保存前手动补充。
- 网站改版后可能需要更新对应的选择器。
